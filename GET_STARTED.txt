================================================================================
                            WHAT WAS IMPLEMENTED
================================================================================

POST /api/patient-chat
├── Input: patientId (string) + question (string)
├── Auth: Requires session
├── Database: Retrieves from local SQLite (clara.db)
├── Output: Patient-specific clinical summary (SQL or LLM)
└── Security: Parameterized SQL, patient isolation enforced

KEY FEATURES:
  ✅ Patient-Specific: Only selected patient's records retrieved
  ✅ Isolated: No cross-patient data possible (parameterized SQL)
  ✅ Chronological: Organized by admission, ordered by date
  ✅ Complete: 5 data types (admissions, diagnoses, meds, labs, ICU)
  ✅ Accurate: Only actual database records, no fabrication
  ✅ Optional LLM: Gemini API for natural-language summaries
  ✅ Fallback: Structured SQL summary if API key not configured
  ✅ Secure: Authentication required, server-side API key management

   3. Prescriptions → WHERE subject_id = ?
