# Ollama Setup Guide for CLARA Phase 5

## What is Ollama?

Ollama is a local LLM runner that allows you to run large language models on your machine without cloud APIs. It's perfect for clinical summarization tasks.

## Installation

### Option 1: Download from ollama.com (Recommended)

1. Visit: https://ollama.com
2. Download the installer for your OS (Windows, Mac, Linux)
3. Run the installer and follow prompts
4. Ollama will be installed in your system

### Option 2: Docker (If you have Docker installed)

```bash
docker run -p 11434:11434 ollama/ollama
```

## Starting Ollama

### Windows/Mac/Linux (After Installation)
```bash
# Ollama typically starts as a service automatically
# Or start manually:
ollama serve
```

The service should listen on `http://localhost:11434`

## Downloading a Model

Once Ollama is running, download a clinical-friendly model:

```bash
# Option 1: Mistral (7B - fast, good quality)
ollama pull mistral

# Option 2: Neural Chat (7B - optimized for conversations)
ollama pull neural-chat

# Option 3: Llama 2 (7B - popular, capable)
ollama pull llama2
```

**Recommended**: Use `mistral` (fastest, ~4GB download)

## Verify Ollama is Running

```bash
# Check if Ollama is accessible
curl http://localhost:11434/api/tags

# Should return JSON with available models
```

## Using with CLARA

### 1. Start Ollama
```bash
ollama serve
```

### 2. Pull Model
```bash
ollama pull mistral
```

### 3. Set Environment Variables
The backend automatically looks for:
- `OLLAMA_API_URL=http://localhost:11434` (default)
- `OLLAMA_MODEL=mistral` (default)

These are in `.env` file in `/backend` directory.

### 4. Start CLARA Backend
```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

### 5. Test Integration
```bash
# Check health endpoint
curl http://localhost:8000/health

# Should show:
# {"status": "ok", "ollama_available": true}

# Generate a summary (will use LLM if Ollama is running)
curl -X POST http://localhost:8000/api/patients/PAT001/summary \
  -H "Content-Type: application/json" \
  -d '{}'
```

## Performance Notes

- **First Run**: Model takes ~2-5 min to load from disk
- **Subsequent Runs**: ~5-10 seconds per summary generation
- **Memory**: Mistral 7B needs ~4GB RAM
- **Disk**: Models take 4-8GB storage

## Troubleshooting

### Issue: Ollama not responding
```bash
# Check if Ollama is running
curl http://localhost:11434/api/tags
# If fails, start with: ollama serve
```

### Issue: Model not found
```bash
# List available models
ollama list

# Pull if missing
ollama pull mistral
```

### Issue: Slow responses
- Ensure model is fully downloaded
- Check system RAM availability
- Consider smaller model if needed

### Issue: CLARA showing "template" mode instead of "local_llm"
- Verify Ollama service is running
- Check `OLLAMA_API_URL` in `.env` is correct
- Restart CLARA backend after starting Ollama

## Fallback Behavior

If Ollama is not available, CLARA automatically falls back to template-based summaries without any errors. This ensures the system always works.

## Quick Start (TL;DR)

```bash
# 1. Install Ollama from ollama.com
# 2. Open terminal and run:
ollama pull mistral
ollama serve

# 3. In another terminal:
cd backend
uvicorn app.main:app --reload --port 8000

# 4. Test in browser:
# Open http://localhost:8080/INDEX.html
# Login as patient
# View profile → summary should be generated by LLM
```

## System Requirements

- **CPU**: Any modern processor (Intel i5+ or AMD equivalent)
- **RAM**: 8GB minimum (16GB recommended for smooth operation)
- **Disk**: 10GB free space (for models)
- **Internet**: Only needed for downloading models first time

---

**Note**: Ollama is completely free and open-source. No API keys needed, no cloud costs, data stays local.
